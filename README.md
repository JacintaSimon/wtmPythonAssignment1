# Python Practice Exercises

A collection of Python programs covering core data structures — lists, tuples, sets, and dictionaries — including student information management exercises.

## Contents
- `assignment1.py` — Student dictionary examples (creating, printing, and storing multiple student records) also,  Combined data structures assignment using lists, tuples, sets, and dictionaries to manage student information

## Topics Covered
- Lists, Tuples, Sets, Dictionaries
- Basic data manipulation (add, remove, update)
- Working with duplicate values and uniqueness (sets)
- Formatting and printing structured data
